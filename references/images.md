# 图片参考与归档

## 提炼范围

先查看上传、本地或网页中的实际图片，再按用户指定范围提炼。无法读取时说明缺少的材料。

提炼用于借鉴视觉设计；抠图、去除人物、沿用原背景等要求按实际图片编辑处理。

| 类别 | 提炼重点 |
| --- | --- |
| 画风 | 形体、线条、边缘、上色、色彩关系、纹理与细节分配 |
| 姿势构图 | 动作、重心、肢体、视线与人物关系，以及视角、景别、主体占比、位置与留白 |
| 光影 | 光源方向与软硬、明暗分布、冷暖关系、轮廓光和环境反射 |
| 背景 | 空间、景物、建筑、材质、远近层次与氛围 |

服装、表情、配色、道具等按需新增类别。姿势与构图保持合并，纯风景只分析其中适用的构图部分。

按指定范围转译到目标画面：借光影时沿用目标画风，借姿势构图时适配目标角色的服装、体型和道具。用户只说“喜欢”时结合上下文判断值得借鉴的部分，关键歧义才补问。

多图组合说明各图用途，例如“图 1 提供角色，图 2 提供姿势构图，图 3 提供光影”。冲突按目标画面取舍。

## 提炼说明

简记关联原图的相对路径、可复用特征及适配范围，采用可观察的画面描述。例如：

```text
参考图：光影-暖窗侧逆光-01.jpg
借鉴：右后方暖光照亮发丝与肩部边缘，面部处于柔和冷色阴影。
适配：用于窗边等具有后方光源的场景，光源位置随构图调整。
角色、服装和画风沿用目标项目。
```

普通画风、配色与光影氛围可尝试文字复用；特殊笔触、纹理及较准确的姿势构图宜加载原图。沿用背景底图或编辑原图需要实际图片输入。

## 分类与命名

按主要用途分类，沿用已有清楚的命名约定；否则使用：

| 文件 | 建议格式 | 示例 |
| --- | --- | --- |
| 可复用参考图 | 类别-核心视觉特征-序号.ext | `光影-暖窗侧逆光-01.jpg` |
| 姿势构图参考 | 姿势构图-动作与镜头特征-序号.ext | `姿势构图-回身仰视半身-01.jpg` |
| 当前项目的角色参考 | 角色-名称或辨识特征-序号.ext | `角色-银发红丝带-01.png` |
| 新成图或修改版 | 主题-主体-v版本.ext | `雨夜赴约-银发少女-v1.png` |
| 同轮多个候选 | 主题-主体-v版本-候选序号.ext | `雨夜赴约-银发少女-v1-02.png` |

使用少量可检索的视觉关键词，未知角色按可见特征命名。文件名符合 Windows 规则，扩展名匹配实际格式。

可复用参考图与说明同名配对，如 `光影-暖窗侧逆光-01.jpg` 与 `光影-暖窗侧逆光-01.md`。

同图多用途只存一份，在说明中补充用途并从相关条目链接。重名先检查已有文件：同一素材复用，不同素材递增序号，成图修改递增版本。

## 保存与后续调用

收藏或长期复用的图片与说明保存到共享参考目录，本次专用参考随项目保存。归档时保留原图，整理已有文件时更新关联路径。

后续按条目名称读取说明，按需加载原图并实际附给生图工具。无法取得原图时说明情况，根据本次目标使用文字或补充材料。
