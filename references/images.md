# 图片参考与归档

## 提炼目标与范围

将用户指定的可见特征转写为可直接用于 GPT Image 的提示词片段，并明确借鉴范围；不声称还原原始提示词。

先查看上传、本地或网页中的实际图片，再确定本次提炼画风、姿势构图、光影、背景还是整图。无法读取时说明缺少的材料。

| 类别 | 提炼重点 |
| --- | --- |
| 画风 | 造型概括、线条与边缘、上色和阴影、色彩关系、纹理分布、细节层级 |
| 姿势构图 | 身体朝向、视线、重心、肢体与接触关系、视角、景别、主体占比、遮挡和留白 |
| 光影 | 可见光向、软硬、明暗分布、冷暖关系，以及不同材质的受光表现 |
| 背景 | 空间层次、透视关系、主要景物、布局、疏密和氛围 |

服装、表情、配色、道具等按需新增类别。姿势与构图保持合并，纯风景只分析适用部分。

按范围区分可复用特征与具体内容。例如，提炼画风时辨认通用造型和画法，另辨本张角色、服装、道具、姿态、配色与光照；不自动将后者固化为画风。借姿势构图时适配目标体型与服装，借光影时沿用目标画风。抠图、去除人物或沿用背景底图按实际图片编辑处理。

## 观察与转写

- **依据可见证据。** 结合整体和必要局部判断，考虑缩放、压缩或预览异常。区分明确可见、可能如此和无法判断的内容；不把推测的绘画工具、被遮挡结构或看不清的微纹理写成确定要求。可以描述“彩铅般的细涩线缘”，不据此认定原作使用彩铅。
- **描述关系、位置与程度。** 用可观察的画面关系替代孤立的审美形容词。例如“叠压处描线较深，浅色布面内线较轻；短排线集中于折边，开阔亮面保持完整”。纹理尤其交代强度与分布，避免将局部现象扩大到全图。
- **区分共同核心与变化。** 多图对照时判断共同点属于画法还是题材，保留有依据的配色、材质和笔触变化范围。单图只支持该图可见范围，不声称已覆盖整套画风。
- **按参考决定取舍。** 干净、颗粒、渐变、平涂等都不是通用质量标准。保留有辨识力的特征，排除可确认的输入伪影；不预设统一的去纹理要求或堆叠无依据的排除词。

## 提炼产物

提示词正文只保留可执行的视觉描述及必要借鉴边界，可用自然段或短分节；长度以保留辨识力和消除歧义为准，不设机械字数上限或固定语言。

将正文与参考索引分开。索引集中记录原图位置、各图用途、必要的适用范围和验证状态；正文不混入文件路径、分析过程、历史反馈或文件管理说明。通用画风按[画风模板](style-template.md)保存；单图提炼说明可在同名 Markdown 中将正文与索引分区，避免为简单素材增加文件。

实际创作时，按[创作与反馈](creation.md#实际提示词组装)保留所选预设正文，另写本次主体、动作与构图；部分借鉴按用户明确范围取用。各输入图片按实际顺序说明用途，保留必要原图补充文字难以完整描述的笔触与空间关系。模型、质量、尺寸等工具参数按接口另行设置，不用提示词声称设置了未开放的参数。

## 核对与验证

交付前对照原图检查：描述是否有可见依据，是否混入无关内容，特征之间是否冲突，适用范围是否超出证据。未经过生成验证的提炼稿，在索引中标明“待生成验证”。

用户要求生成验证时，保持可控制的提示词、参考与参数一致，先检查关键特征能否复现，再逐项调整；实际调用遵守[纠偏与停止条件](creation.md#纠偏与停止条件)。通用画风还应通过更换主体检查可迁移性。一次返图的偶发问题不直接改写通用规则，验证结论保留实际适用范围。

## 分类与命名

按主要用途分类，沿用已有清楚的命名约定；否则使用：

| 文件 | 建议格式 | 示例 |
| --- | --- | --- |
| 系列或画风参考索引 | 条目名-参考索引.md | `桌上剧团-参考索引.md` |
| 可复用参考图 | 类别-核心视觉特征-序号.ext | `光影-暖窗侧逆光-01.jpg` |
| 姿势构图参考 | 姿势构图-动作与镜头特征-序号.ext | `姿势构图-回身仰视半身-01.jpg` |
| 当前项目的角色参考 | 角色-名称或辨识特征-序号.ext | `角色-银发红丝带-01.png` |
| 新成图或修改版 | 主题-主体-v版本.ext | `雨夜赴约-银发少女-v1.png` |
| 实际生图提示词 | 与对应版本成图同名前缀，扩展名 .txt | `雨夜赴约-银发少女-v1.txt` |
| 同轮多个候选 | 主题-主体-v版本-候选序号.ext | `雨夜赴约-银发少女-v1-02.png` |

使用少量可检索的视觉关键词，未知角色按可见特征命名。文件名符合 Windows 规则，扩展名匹配实际格式。

可复用参考图与单图说明同名配对，如 `光影-暖窗侧逆光-01.jpg` 与 `光影-暖窗侧逆光-01.md`。

同图多用途只存一份，在索引中补充用途并从相关条目链接。重名先检查已有文件：同一素材复用，不同素材递增序号，成图修改递增版本。

## 保存与后续调用

收藏或长期复用的图片与说明保存到共享参考目录，本次专用参考随项目保存。归档时保留原图，整理已有文件时更新关联路径。

用户指定已有条目时，自动读取其正文与参考索引，按本次用途选择原图并实际附给生图工具；已有本地原图不要求用户重复上传。只要求提示词时交付文本即可；无法取得所需原图时说明缺口，不把仅有文字当作已附图。

## 官方依据

以上提炼方法依据官方提示原则设计，不是官方提供的逆向还原算法。

- [GPT Image 提示词指南](https://developers.openai.com/api/docs/guides/image-prompting)：可见细节、参考分工、主体与画风分离、编辑保留项。
- [图像与视觉能力限制](https://developers.openai.com/api/docs/guides/images-vision#limitations)：识别准确性、空间定位与图像缩放。
